# RAFT·설명 감독학습·OPSD·LLMLingua-2 개발 실험

이 문서는 개발·학습 단계 기록이다. 이후 별도 시험셋에서 수행한 110회 추론의 결과와 한계는 [학습과 분리한 시험 결과](holdout_report.md)를 참고한다.

실행일: 2026-11-02 UTC. QLoRA는 사용자 요청에 따라 제외했다. CPU 4코어·16GiB에서 공식 Qwen3-4B BF16 가중치와 일반 rank-4 LoRA를 사용한다. 기존 Q4_K_M GGUF는 별도 보존한다.

## 데이터와 실험 성격

- 공식 원문 5쪽에 근거한 공개 개발 질문 5개, 독립 규칙 그룹 3개.
- 답변과 근거 설명을 별도 task로 만든 지도학습 항목 10개.
- 올바른 근거와 다른 연도/대학의 방해 근거를 함께 제공하는 oracle-context 실험. 검색 정확도 실험이 아니다.
- QA와 Codex 작성 설명은 모두 `pending`이다. 독립 사람 검수, 잠근 시험셋, 60:40 정확도 평가는 수행하지 않았다.
- 원논문 규모를 재현하지 않는 작동 시험이며, 학습 손실 감소를 상담 정확도 향상으로 해석하지 않는다.

## 학습 완료 결과

| 항목 | 관찰 결과 |
|---|---|
| 기본 모델 | Qwen3-4B, BF16, 양자화 없음 |
| 실행 장치 | CPU, PyTorch 2.9.1+cpu |
| RAFT·답변/설명 지도학습 | 10단계 완료, 5개 질문 × 2개 task |
| OPSD | 실제 학생 생성에 대한 전체 어휘 JSD 업데이트 3단계 완료 |

| 어댑터 변화량 | 초기 대비 L2 = 0.94234 |
| 시간 | 1,531.064초, 약 25분 31초. 모델 로딩·전후 답변 생성 포함 |
| 최대 메모리 | 학습 프로세스 peak RSS 9,753.35MiB, 약 9.52GiB. 환경 전체 메모리와 다름 |

OPSD JSD 값은 순서대로 0.06825, 0.02545, 0.05569였다. 서로 다른 질문이므로 이 수치 변화 자체를 성능 향상으로 해석하지 않는다. 모든 단계에서 유한한 loss와 gradient를 관찰했다. 24토큰 학생 생성은 세 번 모두 상한에서 잘렸으며, 완결된 풀이 증류 실험은 아니다.

## 동일한 개발 질문의 전후 답변

질문은 “2026학년도 경희대 지역균형전형도 학교별 추천 인원이 고3의 5%로 제한되나요?”였다. 2026년 근거에는 제한이 없다고 명시되어 있다. 2025년의 5% 제한을 방해 자료로 함께 제공했다.

| 단계 | 관찰한 결론 | 출력 상태 |
|---|---|---|
| 학습 전 BF16 | 2026년에도 5% 제한이라고 잘못 답함 | 192토큰에서 잘림, JSON 미완성 |
| RAFT·답변/설명 지도학습 후 | 제한 없음과 학교폭력 제4호 이상 예외를 설명 | 192토큰에서 잘림. 인용을 ID 목록 대신 긴 객체로 출력 |
| OPSD 후 | 제한 없음과 학교폭력 제4호 이상 예외를 설명 | 137토큰에서 종료, 완결된 JSON과 올바른 근거 ID 목록 |

**최종 답변도 학교장 추천 자체가 필요하다는 조건을 문장으로 명시하지 않았다.** 따라서 기존 QA의 모든 필수 조건을 충족한 완전 정답으로 채점할 수 없다. 또한 이 질문과 답변은 학습에 사용됐다. 관찰된 연도 오류 수정과 출력 형식 개선은 개발 사례이며, 일반화 성능이나 OPSD의 독립적인 우월성을 입증하지 않는다. RAFT와 설명 감독학습을 분리한 ablation, 별도 시험셋 평가는 수행하지 않았다.

최종 개발 출력:

```json
{"answer":"아니요, 2026학년도 경희대학교 지역균형전형의 학교별 추천 인원은 고3의 5%로 제한되지 않습니다. 2026년도 자료에 따르면, 추천 인원은 고교별 추천 인원 제한 없음으로 명시되어 있습니다. 다만, 학교생활기록부에 학교폭력처벌 제4호 이상 처분을 받은 학생은 추천 불가합니다.","citations":["khu-2026-susi:p29"]}
```

## LLMLingua-2 실행 결과

실제 다국어 BERT 기반 공식 LLMLingua-2 모델을 로컬 CPU에서 실행했다. 길이는 Qwen3-4B 토크나이저로 측정했다.

| 조건 | 원문 5쪽의 합계 토큰 | 감소율 | 보호 조항 문자열 보존 |
|---|---:|---:|---:|
| 원문 | 3,783 | — | 41/41 |
| 일반 LLMLingua-2, 목표 유지율 0.5 | 1,867 | 50.65% | 2/41 |
| 규정 조항 보호 방식 | 3,728 | 1.45% | 41/41 |

보존 수치는 보호 조항의 **원문 문자열이 그대로 남는지**를 확인한 값이다. 2/41이 “정확도 4.9%”라는 의미는 아니며, 41/41 역시 답변 정확도를 보장하지 않는다. 원문으로 복귀한 문서는 4개다. 조항 보호 방식은 숫자·부정·예외 등이 있는 문장을 보수적으로 통째로 보존한다.

일반 압축에서 확인한 실제 손실 사례: 경희대 2026 규정의 “학교폭력처벌 제4호 **이상**”이 “학교폭력처벌 제4호”로 바뀌었다. 주거지원 첫 달 규칙의 정액 지급 표현도 줄어들었다. 숫자를 남기는 옵션만으로 조건의 의미가 보존되지는 않는다.

일반 압축은 연구 비교용으로만 저장했다. 상담 CLI의 `--compress-context`는 조항 보호 방식만 사용한다. 낮은 압축률과 분류 모델 실행 비용 때문에 전체 응답이 빨라진다고 주장하지 않는다.

## 실제 상담 연결 확인

학습 후 기존 GGUF 서버를 복구하고 `--compress-context`와 동일한 경로로 경희대 2026년 추천 인원을 질문했다. 검색된 3개 구간의 근거 ID를 유지한 JSON 응답이 출력 검증을 통과했다. 이는 **기존 GGUF + 실제 검색 + 조항 보호 옵션**의 연결 시험이며 새 어댑터의 상담 평가가 아니다.

- 문맥 토큰: 1,684 → 1,684. 이 요청에서는 모두 보호되어 절감이 없었다.
- 압축 전처리: 3.98초, 모델·토크나이저 초기 로딩 포함.
- 전체 요청: 98.66초. 비압축 조건의 대응 실행을 추가하지 않았으므로 속도 개선률은 산출하지 않는다.
- 답변은 추천 인원 제한 없음과 학교폭력 예외를 언급했다. 일부 불필요한 추가 확인 질문은 남아 있다.

따라서 이번 규정 문서에서는 LLMLingua-2의 실용적 속도 이득을 확인하지 못했다. 압축 옵션은 기본적으로 꺼져 있고, 보호 조항을 희생하여 압축률을 높이지 않았다.
