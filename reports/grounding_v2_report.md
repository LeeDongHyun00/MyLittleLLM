# 한국어 조건 수집·입시 규칙 확대 평가

새 12개 시나리오의 자동 통과는 동일 근거 Qwen 5/12, 확대 규칙·보류 11/12다. 이는 AI가 작성한 구조화 시나리오의 공학적 비교다. 독립 전문가 정확도나 새 대학 일반화 성능을 뜻하지 않는다.

## 구현 변경

- 부산대 2026 수시의 추가 지원 횟수, 저소득층학생전형 법정 자격, 특성화고 학교·전문교과 요건을 추가했다. 총 9개 부분 판정 규칙이다.
- `--guided-rule`로 JSON 파일 없이 한국어 문답을 수행한다. 미확인을 false나 0으로 채우지 않고, 결론에 영향을 줄 수 있는 조건을 묻는다. 면제 등으로 결론이 나면 질문을 멈춘다.
- 적용 범위 미확인, 적용 범위 밖, 입력 모순, 연산 시간 초과를 구별한다. 내부 필드명 대신 한국어 확인 질문을 제공한다.
- 실제 입금 여부와 일반 지급 기준·확인 절차를 구분하는 제한된 보류 규칙을 보완했다. 신경망 검증은 사용하지 않았고 모델 가중치도 학습하지 않았다.

## 실제 Qwen 비교

Qwen3-4B Q4_K_M, CPU, temperature 0, seed 42, thinking off, minimal 프롬프트·JSON 스키마·384 출력 토큰이다. 새 규칙 10문항과 개인 기록/일반 기준 질문 2문항을 사용했다. 답변 가능 8개, 보류 필요 4개다. 규칙 문항에서는 양쪽에 동일한 원문 조항과 명시적 시나리오 조건을 제공했고, 나머지는 같은 BM25 상위 2개를 사용했다.

| 조건 | 자동 통과 /12 | 답변 수 /12 | 보류 필요 문항에서 answer 상태 /4 | 불필요 보류 /8 | 경로상 Qwen 호출 수 |
|---|---:|---:|---:|---:|---:|
| qwen_same_evidence | 5 | 11 | 4 | 0 | 12 |
| expanded_rules_gate | 11 | 7 | 0 | 0 | 1 |

실제 Qwen 호출은 12회, 비교한 판단은 24건이다. 같은 생성 결과를 자유 질문 경로에서 재사용했다. API 호출 오류 0건, 출력 잘림 1건이다. 경로별 호출 수를 합산해 실제 생성 횟수로 계산하지 않는다.

코드·요청·원문·정답을 고정한 커밋은 `cc99c19ac6b663a0428dc8820c24094d7c1d9fc7`이다. 응답 확인 후 고정 채점 기준을 바꾸지 않는다. 기존 18개 평가 점수와 합산하지 않는다.

## 개발·회귀 점검

- 코드 테스트 74개 통과. 지원 횟수와 30학점 경계, 법정 대상자 조합, 제외 학교, 미확인 적용 범위, 질문 생략과 미확인 유지 등을 점검했다.
- 기존 18개 시나리오의 요청과 판정 상태·결론·인용을 유지했다. 부족한 조건 안내는 한국어 질문으로 바뀐다. 기존 모델 답변을 재생성하거나 점수를 바꾸지 않았다.
- 보류 의도 개발 예시 12개는 이전 규칙 5/12, 보완 규칙 12/12였다. 이 예시는 수정에 사용한 개발 자료로 일반화 점수에 포함하지 않는다.
- 실제 CLI에 스크립트로 답을 입력해 5회 접수, 횟수 미확인, 첫 학기 면제의 흐름을 확인했다. 세 사례 모두 Qwen 호출 없이 처리됐다. 독립 사용성 시험은 아니다.

## 해석과 남은 일

규칙 검토·갱신과 사용자의 명시적 조건 확인에 비용이 든다. 자연어에서 조건을 자동 추출하거나 외부 개인 기록을 조회하지 않는다. 원문·정답 검수자는 현재 AI이며 독립 전문가 승인은 없다. 작은 새 시나리오에 대한 결과로 운영 정확도를 확정할 수 없다.

보류 필요 문항의 answer 상태는 명시적인 보류 실패를 세는 지표다. 일반 규정을 올바르게 설명하면서 개인 조건의 미확인을 밝히지 않은 경우도 포함되므로, 사실 날조나 실제 합격·지급 확정 주장 건수와 같지 않다.

의미 검토는 정규식 채점이 놓치는 추가 주장·범위·인용 오류를 별도로 기록한다. 공개된 사례를 튜닝에 사용한 이후에는 새로운 독립 자료로 다시 평가해야 한다.

## 전체 답변 검토에서 확인한 점

규칙 확대는 6회 접수 후 추가 1회(V02), 관련 교과 인정 관계 미확인(V09), 마이스터고 제외를 포함한 학교·교과 결합 요건(V10)을 처리했다. V10의 기본 답변은 교과만 언급했으므로, 학교유형 제외를 반영하지 않은 응답으로 구분한다.

기존 접수 횟수 미확인(V03)과 한부모가족지원법 대상 여부 미확인(V06)에서 Qwen은 일반 규정 자체는 맞게 설명했지만 명시적으로 보류하지 않았다. 실제 자격이 있다고 날조한 사례와 같은 의미로 세지 않는다. 개인 입금 질문(V11)에서는 9월 결과보고 의무를 이미 보고되었다는 사건으로 바꾼 오류도 있었다.

자유 질문 V12는 두 경로 모두 실패했다. BM25가 제공한 PDF 23·3쪽 구간에 월 20만원 상한 조항이 없었고, Qwen은 예시 문구와 특수 토큰 모양 문자열을 반복하다 384토큰에서 잘렸다. 1,315 입력 토큰으로 문맥 한도 초과는 아니었다. 형식 검사가 출력 사용을 차단했지만 질문 해결에는 실패했다. 원문 상한 조항은 PDF 10쪽에 있으며 검수 양식에는 이 참고 쪽을 추가했다. 모델 요청·검색 결과·점수는 그대로 보존했다.

기본 모델의 자동 통과 5건 중 V04·V07은 조건을 충족하면 인정된다는 일반 조건문으로 입력 적용 설명이 약했다. 정규식 통과가 완전한 의미 정답을 뜻하지 않는 예다. 반대로 규칙 답변도 거짓 결론의 원인을 학점·학교유형별로 세분화해 설명하는 기능은 아직 제한적이다.

11/12를 운영 정확도 91.7%로 일반화하지 않는다. 현재 우선 보완 대상은 자유 질문의 핵심 근거 검색과 생성 실패 처리이며, 새로운 독립 검수 사례로 효과를 확인해야 한다. 신경망 검증이나 출력 예산 확대만으로 이 실패가 해결된다고 결론내리지 않는다.
