# 학습과 분리한 입시·장학 시험 결과

2026-11-02 UTC에 실제 Qwen3-4B 서버로 **108회 추론**을 완료했다. 기존 5개 개발 질문으로 수행한 SFT 10단계·OPSD 3단계 학습은 이번 객관식 시험에서 일반화 성능을 높이지 못했다. 서술형에서는 개선과 퇴보가 함께 나타났으며, 자동 채점 기준의 한계도 발견했다. 작은 실험 하나로 증류 방법 전체의 효과를 부정하는 결과는 아니다.

## 시험과 실행 조건

- 새 질문 28개, 규칙 그룹 15개. 그중 8개를 선택지 없는 서술형으로도 평가했다. 36개의 독립 질문으로 세지 않는다.
- 부산대 2025·2026 수시 모집요강과 교육부 **2025년 2월** 국가장학금 계획을 사용했다. 어댑터 학습의 규칙 그룹·근거 페이지와 중복은 0개다. 부산대는 어댑터 학습에 등장하지 않았다.
- 정답은 Codex가 공식 원문과 대조했다. 독립 전문가 검수와 대표 표집을 거친 gold는 아니다. 기반 모델의 사전학습 노출 여부는 알 수 없다.
- 같은 Qwen3-4B Q4_K_M 기반에서 기본 모델, SFT 어댑터, OPSD 최종 어댑터를 비교했다. BF16에서 학습한 일반 LoRA를 배포용 Q4 기반에 적용한 결과이며 QLoRA 실험이 아니다.
- CPU 4코어·16GiB, llama.cpp b11960, context 8,192, temperature 0, seed 42, thinking 꺼짐. 매 요청 전 어댑터 적용 상태를 확인했다.
- 입력·정답·모델·채점 코드와 요청 순서를 첫 추론 전에 고정했다. 생성 중 정오답은 확인하지 않았고, 평가 결과를 보고 재학습하거나 프롬프트·채점 기준을 수정하지 않았다.
- 기본 비교는 **40분 18초**, 요청 오류 0건이었다. 요청 시간 합계는 2,417.14초다.

객관식은 정답 근거를 직접 제공하는 원문 이해 시험이다. 네 선택지 중 한 글자만 생성하도록 문법을 제한했다. 서술형은 실제 BM25 top-2 검색 결과를 사용하며, JSON 형식을 요청하되 강제하지 않았다. 출력 상한은 160토큰이다. 두 점수를 합산하지 않는다.

## 서술형 결과를 해석할 때 필요한 오류 검토

**4/8은 자동 어휘·형식·인용 기준의 통과 수이지, 전문가가 판정한 의미 정확도가 아니다.** 아래는 전체 생성이 끝난 뒤 수행한 Codex의 질적 검토이며 원래 점수는 수정하지 않았다.

| 문항 | 관찰과 해석 |
|---|---|
| A02 마감 날짜·시각 | 기본/SFT는 날짜만 답하고 시각을 빠뜨렸다. OPSD는 보류했다. 검색에는 원서접수 마지막 날짜를 언급한 서식과 일정 페이지의 하단만 들어갔고, **17시라는 핵심 조항은 빠졌다**. OPSD의 보류를 단순한 지식 오류로 볼 수 없다. |
| A04 주소·모집단위 수정 | 검색이 근거 페이지를 놓쳤다. 기본/SFT는 관련 없는 페이지로 답변했고, OPSD는 확정을 보류했다. 전체 과제는 해결하지 못했지만 보류와 근거 없는 단정을 같은 오류로 해석하면 안 된다. |
| A08 저소득층 증빙 발급일 | 세 모델의 답변 본문은 9월 5일 이후 원본이라는 규칙을 설명했다. 그러나 SFT/OPSD는 불필요한 follow_up을 이어 쓰다 160토큰에서 잘려 JSON이 미완성됐다. 고정 예산에서의 출력 실패다. |
| A12 복수지원 | 세 모델 모두 올바른 결론과 근거 페이지를 제시해 통과했다. 다만 이미 전제로 준 자격을 다시 확인하는 등 불필요한 후속 질문이 남았다. |
| A16 농어촌 12년 과정 | **자동 채점의 명백한 한계**가 있다. SFT의 “본인만 … 부모의 거주 조건은 면제”는 의미상 맞지만 필수 패턴에 ‘면제’가 없어 실패했다. OPSD가 인용한 PDF 40쪽에도 ‘부·모의 농어촌 거주 조건 면제’가 명시되어 있으나 사전 인용 목록은 111쪽만 포함했다. OPSD의 답은 질문의 부모 거주 요건에 맞는 답이며, 본인 요건 재진술을 요구하는 기준 때문에도 실패했다. 기본 모델은 후속 질문을 늘리다 잘렸다. 따라서 이 문항의 점수만으로 학습 모델의 답이 틀렸다고 할 수 없다. |
| S04·S06 장학금 | 세 모델 모두 우선지원과 지급 확정을 구분했고, 인상 후 교외근로 단가도 맞혀 통과했다. |
| U04 학년도 누락 | SFT/OPSD는 학년도를 확인해 달라고 요청했다. 기본 모델은 홈페이지를 확인하라고만 안내했다. 이 문항에서는 개선을 관찰했다. |

검색의 **페이지 단위 적중은 6/7**이지만 A02는 정답 시각이 있는 구간을 가져오지 못했다. 따라서 페이지 적중률은 필요한 조항의 검색 성공률을 과대평가한다. 서술형 점수에는 검색, 생성, 출력 길이 제한, 불완전한 자동 채점 기준의 영향이 함께 들어 있다. 결과를 본 뒤 이 시험에 맞춰 정답을 추가하거나 같은 질문을 재실행하지 않았다.

## LLMLingua-2 보충 평가

별도 고정 프로토콜에 따라 같은 서술형 8문항의 검색 문맥에 조항 보호 방식의 LLMLingua-2를 적용했다. 입력 전체가 동일한 6문항은 기존 OPSD 응답을 재사용했고, 바뀐 2문항은 한 번씩 추가 추론했다. 기본 비교와 합쳐 **실제 모델 생성은 110회**이며, 재사용한 응답을 추가 독립 추론으로 세지 않는다.

| 항목 | 결과 |
|---|---:|
| 검색 문맥 토큰 합계 | 6,257 → 6,136 |
| 토큰 감소율 | **1.93%** |
| 보호 조항 문자열 보존 | 45/45 · 문항별 중복 포함 |
| 압축 모델·토크나이저 초기화 | 4.05초 |
| 8문항 압축 처리 합계 | 1.75초 |
| OPSD 서술형 형식·종료 통과 | 7/8 → 8/8 |
| OPSD 서술형 엄격 기준 통과 | 4/8 → **5/8** |
| 출력 잘림 | 1/8 → 0/8 |

바뀐 문항은 A02와 A08이다. A02는 압축 후에도 답변을 보류했다. A08은 정답 근거 구간을 그대로 두고 다른 검색 구간이 21토큰 줄어든 뒤, 답변이 **155토큰에서 완결**되어 고정 기준을 통과했다. 압축 전에는 160토큰에서 JSON이 잘렸다. 두 조건의 생성 상한은 같다. 문맥 길이가 서버 한도를 초과했다가 해결된 사례가 아니며, 문맥 변화에 따라 생성 표현이 달라진 한 사례다.

이 결과는 조건부 압축에서 개선 사례 하나를 관찰했다는 의미다. 8문항 중 6개는 완전히 같은 입력이고, 토큰 절감도 작다. 보편적인 정확도 향상이나 전체 응답 속도 향상은 입증하지 못했다. 특히 위 A16 채점 한계는 압축 조건의 5/8에도 그대로 적용된다. 압축 옵션의 기본값은 계속 꺼져 있다.

## 다음 개선의 우선순위

1. **검색과 근거 검증:** 페이지보다 실제 조항을 기준으로 평가하고, 표·일정·예외가 구간 분할로 떨어지지 않도록 한다. 복수의 정당한 근거 위치를 검수한다.
2. **출력 계약과 길이:** 학습 답변을 실제 상담의 JSON 구조에 맞추고 불필요한 follow_up을 줄인다. 출력 예산 또는 문법 제약 변경은 개발셋에서 별도로 비교한다.
3. **검수된 학습·시험 데이터 확대:** 연도 충돌, 숫자 경계, 전형별 예외를 포함한 새 규칙 그룹을 확보한다. 의미가 같은 표현을 허용하는 독립 사람 검수를 추가한다.
4. **증류·압축 효과 재검증:** 이번 시험 결과에 맞춰 수정한 모델의 최종 평가에는 새 시험셋이 필요하다. 이 v1을 반복해서 맞추는 방식은 성능 향상의 증거가 아니다.
