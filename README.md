# MyLittleLLM

Qwen3-4B를 활용해 한국 대학 입시·장학 정보 접근 격차를 줄일 수 있는지 검증하는 프로젝트.

**우선순위 1: 근거를 제시하는 입시 상담. 우선순위 2: 장학금·주거·실부담 비용 안내.** 공식 문서 검색(RAG), 검증 가능한 조건·계산 코드, LLM의 설명을 결합한다.

## 2026-11-02 현재 상태

- 서울대·부산대·경희대의 2025·2026학년도 **수시 모집요강 6개 + 공식 안내서 6개** 수집. 서울대 안내서는 교육청 학교 홈페이지 배포본을 사용했다.
- 장학금 자료를 포함한 URL 레코드 26개 중 18개 다운로드 성공: PDF 14개(1,075페이지), HWPX 1개, HTML 3개. 8개 접근 실패도 목록에 기록했다. 게시물/첨부가 별도 레코드이므로 고유 문서 수와 다를 수 있다.
- 수집기, 페이지별 PDF 추출, SHA-256 스냅샷, 그룹 단위 분할 코드, QA 초안 5개 작성.
- **후속 작업에서 Qwen3-4B Q4_K_M과 llama.cpp를 직접 설치하고 CPU 서버 및 RAG CLI를 실행했다.** 공식 원문 8개에서 비교표 검수 보류 후 1,295개 검색 구간을 사용한다.
- 주거비 지원과 실부담 비용 계산기를 구현했다. 지원 조건과 기간은 명시적으로 확인하며 대출을 장학금으로 차감하지 않는다.
- 공개 개발 예시 5개에 대해 문서 없는 모델/RAG 10회 추론을 완료했다. RAG에서도 전년도 규정 오독과 지급액 오류를 관찰했으며 실패를 포함해 결과를 기록했다.
- 후속 개발 실험에서 **RAFT·답변/설명 지도학습 10단계 + OPSD 3단계**를 CPU에서 실행하고 일반 LoRA 어댑터를 저장했다. QLoRA는 사용하지 않았다. 공식 LLMLingua-2 실행과 조항 보호 압축 옵션도 추가했다.
- 별도 규칙 그룹 15개·시험 질문 28개를 고정하고 세 모델의 객관식 84회·서술형 24회를 실행했다. 객관식은 **기본 22/28(78.6%), SFT·OPSD 각각 21/28(75.0%)**로, 이번 소량 학습의 일반화 개선은 확인하지 못했다.
- 조항 보호 LLMLingua-2 보충 비교에서는 8개 검색 문맥 중 2개만 바뀌어 2회 추가 추론했다. 토큰은 **1.93% 감소**, OPSD의 서술형 엄격 기준 통과는 **4/8→5/8**이었다. 바뀌지 않은 6개 응답은 재사용했으며 실제 생성은 총 110회다.
- **독립 사람이 승인한 gold는 아직 없다.** 새 시험셋은 공식 원문과 대조한 연구용 평가다. 서술형 자동 기준이 맞는 ‘면제’ 표현과 다른 정당한 인용 페이지를 놓치는 문제도 발견하여 보고서에 공개했다. 자동 통과율을 전문가 판정 정확도로 해석하지 않는다.
- HiChunk를 참고한 계층형 검색, 실제 Qwen3 Embedding/Reranker 0.6B, 기존 자료의 질문·근거·답변 예시, 짧은 프롬프트·JSON 스키마를 구현했다. 새 서술형 **16문항·64회**의 고정 기준은 기존 2/16, 검색 변경 2/16, 출력 제어 추가 6/16, 예시 추가 7/16이었다. 개발 프롬프트 비교 8회는 별도다.
- **주된 효과는 출력 잘림 감소이며, 새 검색은 고정 조항 패턴 적중이 12/16→8/16으로 퇴보했다.** 예시의 추가 1점은 정규식의 표현 누락 때문이어서 실제 정확도 향상으로 주장하지 않는다. 기존 CLI 기본값 384토큰과 달리 네 평가 조건 모두 160토큰을 사용했다. 새 경로는 `--pipeline improved`로만 선택하며 기본값은 유지한다.
- 출력 384토큰·짧은 프롬프트·JSON 스키마, 표/조항 전처리, 검색 후보 병합, 계산 도구 연결을 추가했다. **새 12문항·34회 모델 호출(36건 판단)**의 고정 자동 통과는 기존 검색 10/12, 입력 확대 10/12, 전처리 9/12였다. 모두 출력 잘림은 없었지만 **전처리의 정확도 향상은 확인하지 못했다.** 부정 해석과 답변 보류 오류를 공개했다. `--pipeline concise`와 `--pipeline preprocessed`는 선택 옵션이며, 이번 비교에서는 concise가 생성 비용이 낮았다.
- 원문에 연결한 **6개 규칙군의 AST·Z3 판정, 정보 부족 보류, 조건부 계산**을 추가했다. 구조화 조건을 제공한 새 18개 시나리오의 자동 통과는 같은 근거를 받은 Qwen 13/18, 규칙·보류 18/18, 신경망 검증까지 결합 15/18이었다. `--pipeline grounded`는 규칙·보류를 기본으로 사용하며 검증 필터는 `--claim-check`로만 선택한다. **새 규칙·대학 일반화나 자연어 조건 추출 정확도는 검증하지 않았다.** MiniCheck는 한국어 개발 입력을 구분하지 못했고 다국어 NLI도 오답을 승인했다. 독립 검수 전 운영 정확도 100%로 해석하지 않는다.
- 부산대 수시 추가 지원 횟수·저소득층 법정 자격·특성화고 전문교과 규칙을 더해 **총 9개 규칙**과 한국어 문답 `--guided-rule`을 제공한다. 미확인 값을 보존하고 결론에 필요한 조건을 묻는다. 새 12개 사례의 자동 통과는 같은 근거 Qwen **5/12**, 확대 규칙·보류 **11/12**였다. 남은 자유 질문 1건은 상한 조항 검색 누락과 생성 반복·잘림으로 두 경로 모두 실패했다. 코드 테스트 74개 통과, 기존 18개 요청·판정 유지, 별도 문답 CLI 3건을 확인했다. 독립 검수용 빈 양식을 만들었으며 **독립 전문가 검수는 아직 완료되지 않았다.**

## 제안한 학습 방식의 수정

모집요강은 근거 문서이고 해설은 정답 후보 자료다. 질문마다 적용 학년도·전형·조건·예외·근거 페이지를 연결하고 검수해야 정답셋이 된다.

60:40은 **개발 60% / 잠근 시험 40%**로 유지하되, 개발용을 나누어 전체 기준 **학습 48% / 검증 12% / 시험 40%**로 시작한다. 같은 규칙의 연도별 버전·바꿔 쓴 질문·문서 복사본은 한 그룹으로 묶는다. 그룹 크기 때문에 실제 문항 비율은 달라질 수 있다.

현재 GGUF RAG와 BF16 Qwen3-4B의 소규모 LoRA·OPSD 작동 시험 및 별도 규칙 평가를 완료했다. 이번 시험은 이미 학습한 5개 질문에 대해 새 규칙을 분리한 평가이며, 처음 제안한 60:40 비율 실험을 완료한 것은 아니다. 정식 효과 비교에는 독립 검수와 새로운 시험셋이 필요하다. 미세조정으로 매년 바뀌는 요강을 암기시키는 것만으로는 최신 상담 정확도를 보장할 수 없다.

## 데이터 수집

Python 3.10 이상. PDF 추출에는 pypdf를 사용한다.

```bash
python -m pip install -r requirements-data.txt
python scripts/collect_sources.py
```

일부 자료만 다시 받을 때:

```bash
python scripts/collect_sources.py --ids snu-2026-susi khu-2026-guide --output outputs/retry.jsonl
```

- 입력 목록: `data/sources.jsonl`
- 이번 수집 결과: `data/retrieval_snapshot.jsonl`
- 원문: `data/raw/` (Git 제외)
- PDF 페이지별 추출: `data/extracted/` (Git 제외)
- 새 실행 결과: `outputs/retrieval.jsonl` (Git 제외)

표·각주의 자동 추출 오류는 별도 검수한다. 부산대 2025 가이드북 31페이지는 OCR이 필요하다. HWPX와 HTML은 원본을 수집하며 현재 수집기에서 본문을 추출하지 않는다. 파일의 다운로드 성공은 정답 승인이나 학습 이용 허가를 의미하지 않는다.

## 검수 후 분할

```bash
python scripts/split_dataset.py data/private/reviewed_qa.jsonl --output outputs/frozen-v1
```

`review_status=approved`인 QA만 받는다. 실제 검수자·근거를 남긴 후 사용한다. 입력에 동일 질문이 다른 그룹으로 나타나면 중단하고, 이미 존재하는 출력 폴더에는 시험셋을 덮어쓰지 않는다. 의미가 같은 규칙의 자동 탐지는 구현하지 않았으므로 `leakage_group` 검수는 필수다.

새 대학 일반화 실험은 대학 수를 확대한 뒤 `--group-key institution_group`으로 별도로 분할한다. 연도 갱신 실험은 이 그룹 분할과 다른 평가 프로토콜이다.

## 코드 검증과 모델 연결 확인

```bash
.venv/bin/python -m unittest discover -s tests -v
python scripts/probe_model.py --base-url http://127.0.0.1:8080/v1
```

테스트는 그룹 누출 방지, 미검수 답안 거부, 범위별 검색, 인용 ID 검증, 주거비 상한과 첫 달 예외, 대출과 비용의 구분을 검사한다. 코드 테스트 통과는 모델 답변의 정확도를 보장하지 않는다.

원문 파일 전체와 전체 검색 문맥은 저장소에 재배포하지 않는다. URL·해시·수집 상태, 자체 작성한 문서/QA와 검증에 필요한 소량의 예시 근거 발췌를 공개한다. 원문별 이용 조건은 목록의 `license_note`에 기록한다.
