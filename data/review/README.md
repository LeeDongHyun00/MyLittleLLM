# 독립 검수 대기 자료

`grounding_v2_blind_review.csv`는 질문, 사용자가 제시한 조건, 적용 범위, 원문 링크와 PDF 쪽을 담는다. 제안 정답과 모델 응답은 제외했다. 검수자와 검수일은 아직 비어 있다. 이 파일이 존재한다고 독립 검수가 완료된 것은 아니다.

검수자는 먼저 원문으로 답할 수 있는지 판단하고, `reviewer_answer`에 결론 또는 보류 이유, `reviewer_citations`에 근거 조항, `reviewer_name`과 `reviewed_at`에 실제 검수 기록을 작성한다. 질문의 모호함, 예외 누락, 조건 간 충돌은 `notes`에 남긴다. 독립 답안을 작성한 뒤 제안 정답이나 모델 응답과 비교한다.

입시 규칙은 해당 모집요강의 부분 조건이다. 최종 합격, 모든 지원자격, 법정 대상자 지위의 실제 확인을 답안에서 추정하지 않는다. 주거장학금 개인 입금 질문은 일반 사업계획만으로 확인할 수 없다.

이 사례들은 이미 구현·개발에 사용된 규칙을 공유한다. 사람 검수가 추가되더라도 새 대학·새 규칙에 대한 독립 시험으로 소급 변경하지 않는다. 다음 일반화 평가를 위해서는 별도 사례를 작성·검수하고 고정해야 한다.
