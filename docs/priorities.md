# Qwen3-4B 교육격차 프로젝트 우선순위

작성: 2026-11-02. 아래 순위는 구현 가능성, 정보 접근 격차와의 관련성, 오류를 검증할 수 있는 정도를 종합한 **프로젝트 판단**이다. 논문이 이 순위를 실험으로 검증했다는 뜻은 아니다.

| 순위 | 구현 대상 | 첫 결과물 | 성공 판정 | 한계 |
|---|---|---|---|---|
| 1 | 근거를 제시하는 대입 정보 상담 | 연도·대학·전형을 확인하고 지원자격, 수능 최저, 제출서류, 일정에 원문 근거를 붙여 답변 | 핵심 조건 정확도, 근거 충실도, 잘못된 지원 불가 판정률 | 합격 확률이나 학생부의 실제 평가 결과는 모집요강만으로 알 수 없음 |
| 2 | 장학금·주거·실부담 비용 안내 | 국가/교내 장학금 자격·신청 절차 안내, 등록금과 주거비 시나리오 계산 | 자격·금액·학기 정확도, 중복지원 오류, 비용 산식 검증 | 장학금 예산·선발 및 기숙사 배정은 확정할 수 없음 |
| 3 | 교사·진학상담사 업무 보조 | 학생이 확인해야 할 조건과 근거 문서 초안 | 상담 시간과 누락률, 교사 검토 결과 | 최종 판단은 담당자 확인 필요 |
| 4 | 검증된 문항을 이용한 학습 힌트 | 오답 유형에 맞는 단계적 힌트 | AI 없이 치르는 사후평가 | 답안 제공만으로 학습 향상을 추정할 수 없음 |
| 5 | 입학 후 학습·지원제도 연결 | 학업·장학·학사 상담 연결 | 서비스 이용·중도탈락 등 장기 지표 | 별도 학사 자료와 장기 검증 필요 |

## 1번의 구현 범위

질문 → 대학·학년도·전형 확인 → 해당 버전의 공식 문서 검색 → 조건/예외 확인 → Qwen의 쉬운 설명 → 원문 URL·PDF 페이지 표시.

첫 파일럿은 서울대·부산대·경희대의 **2025·2026학년도 수시**다. `2025년에 발행한 자료`와 `2025학년도에 적용하는 자료`를 구분한다. 정시, 편입, 재외국민 전형은 이번 원문 묶음에 포함하지 않았다. 향후 정시를 추가해야 수능 중심 상담까지 다룰 수 있다.

지원자격과 합격 가능성을 구분한다. 예를 들어 학교장 추천이 필요한 전형은 추천 여부를 확인하고, 성적만으로 추천이나 합격을 보장하지 않는다. 확인되지 않은 정보는 질문하거나 담당 입학처 확인으로 연결한다.

## 2번의 구현 범위

먼저 국가장학금과 주거안정장학금의 **연도·학기별 자격 및 신청 안내**를 구현한다. 실부담 계산은 해당 대학/학과의 등록금, 기숙사 식비 포함 여부, 거주 기간, 장학금 중복지원 기준을 확보한 후 추가한다.

계산은 검증 가능한 코드가 담당한다. 같은 기간의 비용을 맞추고 다음 항목을 분리한다.

- 등록금 순부담 = 등록금 − 등록금 범위 내에서 실제 적용 가능한 장학금.
- 생활 순부담 = 기숙사/월세·식비·교통비 − 중복수혜 조건을 만족하는 생활비 지원.
- 대출은 당장의 현금 부족을 줄이지만 갚아야 할 부채다. 장학금처럼 총비용에서 빼지 않는다.
- 예상 지원금과 확정 지급액을 구분하고, 소득만으로 학자금 지원구간을 단정하지 않는다.

등록금·기숙사 요금표와 교내 장학 규정은 아직 별도 수집·검증이 필요하다. 이번 목록만으로 전국 대학 실부담 계산기를 완성했다고 주장하지 않는다.

## 왜 이 순서인가

저소득 학생에게 정보 접근, 비용 이해와 지원 절차는 개입 가능한 문제다. 다만 정보 상담이 사교육 자원, 지역의 교과 개설 격차, 대학 정원 및 선발 제도를 직접 바꾸지는 않는다.

- [Lee 외, Financial Aid, Tuition Controls, and Access to Selective Higher Education](https://link.springer.com/article/10.1007/s11162-025-09879-x): 재정 지원과 선택적 대학 접근을 함께 검토해야 한다는 배경 근거. 이 연구로 Qwen의 효과가 입증되는 것은 아니다.
- [Yong 외, Educational aspirations and inequality](https://link.springer.com/article/10.1007/s10734-025-01518-9): 포부뿐 아니라 경로와 실제 진학 기회의 차이를 살필 필요가 있다.
- [국가장학금 정책과 소득계층별 대학·전공 선택 연구](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003283385): 비용과 진학 선택의 연결을 연구할 필요성.
- [Tutor CoPilot](https://arxiv.org/abs/2410.03017): 교사/튜터 보조라는 개입 방식의 참고 사례. 모델과 환경이 달라 Qwen3-4B로 결과를 일반화할 수 없다.

## 모델 선택과 적용

사용자가 보고한 모델은 `Qwen3-4B-Q4_K_M.gguf`, API 모델명 `Qwen3-4B`다. 원본 Qwen3-4B인지 후속 Instruct/Thinking 변형인지는 GGUF 메타데이터와 서버 설정을 확인해야 한다.

[원본 공식 모델 카드](https://huggingface.co/Qwen/Qwen3-4B)는 약 40억 파라미터의 텍스트 모델과 thinking/non-thinking 사용을 설명한다. [공식 GGUF 저장소](https://huggingface.co/Qwen/Qwen3-4B-GGUF)는 추론 배포의 참고 자료다. 양자화된 모델의 한국어 입시 정확도는 이 프로젝트에서 별도 측정해야 한다.

GGUF 서버로 먼저 검색 기반 추론을 검증한다. 미세조정이 필요하면 대응하는 Hugging Face 원본 가중치와 토크나이저로 LoRA/QLoRA를 학습하고, 이후 같은 배포 조건으로 변환·양자화해 비교한다. 현재 GGUF 파일을 일반적인 Transformers 학습 코드에 그대로 넣는 계획은 적절하지 않다.
