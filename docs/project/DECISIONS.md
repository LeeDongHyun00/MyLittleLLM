# 결정 기록

아래는 기존 작업과 사용자 지시를 2026-11-04에 정리한 기록이다. 과거 결정이 그 날짜에 처음 내려졌다는 뜻은 아니다.
계약 변경은 ID·이유·근거·영향을 추가한다. 폐기 결정도 지우지 않고 대체 결정으로 연결한다.

| ID | 상태 | 결정과 이유 | 근거/영향 |
|---|---|---|---|
| ADR-001 | 유지 | 우선순위는 근거 있는 입시 상담, 장학/주거/비용 안내 | [초기 우선순위](../priorities.md). 입시 범위는 3개 대학 2025/2026 수시 |
| ADR-002 | 유지 | 해설을 자동 gold로 취급하지 않고 공식 조항과 검수 연결 | [실험 설계](../experiment_design.md). 그룹 분할 48/12/40은 아직 정식 실행 미완료 |
| ADR-003 | 유지 | 사용자 요청에 따라 QLoRA 대신 증류 연구·LLMLingua-2 진행 | [증류 실행](../distillation.md). 일반 LoRA SFT/OPSD는 실행했으나 [객관식 개선 없음](../../reports/holdout_report.md) |

| ADR-005 | 유지 | 신경망 검증을 기본으로 켜지 않음 | [한국어 비교](../../reports/grounding_report.md). 과도한 보류와 오답 승인을 관찰함 |

| ADR-007 | 유지 | 공개 평가 결과와 실패를 보존하고 새 시험과 구분 | [v2 의미 검토](../../reports/grounding_v2_qualitative_review.json). V12 및 자동 채점 한계 공개 |

| ADR-009 | 다음 작업 설계 | 검색 조항 누락과 생성 반복을 별도 실험으로 다룸 | V12 원인 두 개를 한 번에 바꾸면 기여도를 구분하기 어려움. [R01/M01](TASKS.md) |
| ADR-010 | 이번에 채택 | 참고 프로젝트 순위는 우리 목적의 참고 우선순위로 표시 | 스타는 공개 관심 지표일 뿐 성공률/한국어 입시 정확도가 아님. 릴리스·코드/테스트 정의·라이선스를 함께 기록 |
| ADR-011 | 요청 범위에서 채택 | 명시적 사용자 요청에 따라 S0·S2·S3 작업 세션을 분리하고 push/PR 이벤트로 검사·인수인계 표를 연결 | [협업 운영](COLLABORATION.md). 외부 webhook 관리 API는 403, 수신 URL도 없음. Actions 네이티브 이벤트를 사용하며 상시 세션 생성기로 표시하지 않음 |
| ADR-012 | 상태 반영 | E01은 준비 완료, D01은 별도 배포본 진단만 완료 | [E01](../evaluation/e01_protocol.md), [D01](../../reports/d01_source_report.md). H1/새 gold/잠금은 대기이며 미러를 기존 원문 해시로 대체하지 않음 |
| ADR-013 | 후보 채택 보류 | R01 두 후보를 기본 검색에 적용하지 않고 공개 개발 실패를 보존 | 문장 가중치는 개선 없음. 조항 창은 V12를 찾지만 완전 근거 묶음이 8/11→6/11로 퇴보. BM25 k=2 기본값 유지 |
| ADR-014 | 개발 구현 채택 | L01의 입증된 false 필요 조건 설명을 선택적 설정으로 통합, 계약 1.1.0 | [L01](../../reports/l01_rule_boundaries.md), [INTERFACES](INTERFACES.md). 외부 키/판정 AST 유지, 설명 문자열 변경. H1/실서비스 지연 미검증, 모든 E02 arm의 L 버전은 동일하게 동결 |

계약 1.0.0 최초 작성은 문서와 자동 검사만 변경했다. 이후 1.1.0에서 위 협업 메타데이터와
L01 선택적 설명을 추가했다. 기존 동결 평가·모델 설정·기본 검색은 보존했다.
참고 프로젝트의 전체 스택, 상시 자동 세션 오케스트레이터, 자동 장기 메모리 서버는 아직 채택하지 않았다.
