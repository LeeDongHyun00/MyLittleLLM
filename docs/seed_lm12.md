# SeedLM-12: 반복하면 사라지는 효과

작성일: 2026-11-20. [SeedLM-10/11](seed_lm10.md)의 후속이다. 사전학습 가중치 없이 처음부터 학습하고, 측정은 모두 이 저장소 환경(CPU 4코어)에서 했다.

## 요약

- SeedLM-9에서 같은 데이터 구성의 두 실행이 교사 보류 과제에서 62와 53으로 갈렸다. 그렇다면 SeedLM-6의 핵심 주장(접붙이기 데이터가 조합을 가르친다: s5-var 52 → s6-graft 61)도 한 번의 실행에 기댄 것이다. 이번에는 접붙이기가 없는 구성(A)과 있는 구성(B)을 시드 셋씩, 40분씩 학습해 같은 측정을 반복했다(측정 전에 등록).
- 결과는 시드별로 B − A = +1, +1, −8, 평균 −2.7이다. 등록 기준(평균 +4 이상, 모든 쌍에서 B가 앞섬)과 거리가 멀어 **기각**한다. 처음 보는 조합 77개에서도 평균이 같았다(A 21.3, B 21.3). SeedLM-6의 +9는 재현되지 않았다.
- 대신 짧은 학습의 이점은 반복해서 보였다. 40분 코더 여섯은 교사 보류 과제에서 54~62개(평균 59)를 풀었다. 120분 학습한 s5-var는 52개였다.
- 실제 보류 개발 과제에서는 여섯 모두 최선 67~69로, 채택 기준(69 초과)을 넘지 못했다.

## 1. 설계

`reports/seedlm/seedlm12_protocol.json`. 두 구성 × 시드 1, 2, 3, 각 40분(학습률은 40분에 걸쳐 120분 때와 같은 모양으로 줄어든다). A는 s5-var의 데이터(변형 과제 10%), B는 A에 접붙이기 10%를 더했다. 시드는 초기화, 데이터 순서, 합성 행, 접붙이기 설명 낱말을 바꾼다. 학습은 A1, B1, A2, B2, A3, B3 순서로 번갈아 했고, 학습 중에는 아무것도 같이 돌리지 않았다.

## 2. 결과

|---|---|---|---|---|---|---|
| A1 | 2,087 | 59 | 20 | 39 | 56 / 68 | 4 |
| A2 | 1,959 | 59 | 21 | 38 | 53 / 68 | 2 |
| A3 | 1,943 | 62 | 23 | 39 | 58 / 68 | 4 |
| B1 | 1,981 | 60 | 22 | 38 | 59 / 67 | 4 |
| B2 | 1,851 | 60 | 23 | 37 | 55 / 69 | 3 |
| B3 | 1,757 | 54 | 19 | 35 | 56 / 67 | 4 |
| **평균 A / B** | | **60.0 / 58.0** | 21.3 / 21.3 | 38.7 / 36.7 | 55.7 / 56.7 · 68 / 67.7 | |

- 주 측정: B − A가 +1, +1, −8. 기각.
- 시드 사이의 폭은 A 안에서 3, B 안에서 6이었다. 120분 학습에서 본 9의 차이보다 작다. 길게 학습할수록 작은 데이터를 외우는 정도가 실행마다 달라져 흔들림이 커지는 것으로 보인다.
- B는 같은 40분에 걸음을 5~10% 덜 갔다(접붙이기 행이 들어간 학습은 매번 조금 느리다).

## 3. 무엇이 바뀌나

SeedLM-6의 결론("잇는 방식의 가짓수가 조합을 가르친다")은 철회한다. 그때의 +9는 한 번의 120분 실행끼리의 비교였고, 같은 구성의 반복 실행 사이에서도 그만한 차이가 났다(SeedLM-9의 62 대 53). 시드를 바꿔 반복하자 효과가 사라졌다. [지금까지의 요약](seedlm_findings.md)의 2절도 이에 맞춰 고쳤다.

남는 것은 두 가지다.

1. 학습을 짧게 하면 보류 과제에서 낫다. 120분 코더들(52~62)보다 40분 코더들(54~62, 평균 59)이 대체로 높고, 같은 실행 안에서도 30분 시점이 120분보다 나았다(SeedLM-9, 57 대 53).
2. 따로 학습한 코더들의 합의는 증거다(SeedLM-10). 이번 40분 코더 여섯(SeedLM-10과 겹치는 코더 없음)으로 같은 합의를 다시 쟀다(`reports/seedlm/ensemble_s12.json`).

| | 교사 보류 139 | 범위 밖 15 | 개발 과제 94 (코더 혼자) |
|---|---|---|---|
| 단일 코더 (최저 ~ 최고) | 54 ~ 62 | 2 ~ 4 | 53 ~ 59 |
| **여섯의 합의** | **71** | 3 | 61 |
| 누구라도 맞힘 | 87 | 6 | 69 |
| SeedLM-10의 일곱 코더 합의 | 70 (최고 단일 62) | 3 | 62 |

전혀 다른 코더 여섯에서도 합의는 가장 좋은 단일 코더보다 9개 많았다(62 → 71). SeedLM-10의 결과(62 → 70)가 재현됐다. 실제 개발 과제에서는 이번에도 엔진 쪽으로 옮겨지지 않았다(엔진이 확신하지 못하는 과제만 합의로 바꾸면 63, 같은 규칙에 첫 코더 하나를 쓰면 65). 이 실험 묶음에서 반복해도 살아남은 효과는 짧은 학습과 코더 간 합의 두 가지다.

앙상블을 더 밀고 나간 실험들(SeedLM-13, 15~19)은 [별도 문서](seed_lm13.md)에 모았다.

## 한계

- 시드 셋은 적다. 평균 차이 −2.7의 신뢰구간은 넓다. 다만 등록한 기준(모든 쌍에서 B가 앞섬)은 세 번째 쌍에서 크게 깨졌다.
- 40분 실행은 120분 실행과 다른 머신(재시작 뒤)에서 돌았다. 120분 코더와의 비교에는 학습 시간과 머신 차이가 섞여 있다.

## 재현

```bash
for seed in 1 2 3; do
  python scripts/seedlm4_train.py --name s12-a$seed --minutes 40 --seed $seed --variant-share 0.1
  python scripts/seedlm4_train.py --name s12-b$seed --minutes 40 --seed $seed --variant-share 0.1 --graft-share 0.1
done
python scripts/seedlm5_fragments.py --model s12-a1      # 여섯 코더 각각
python scripts/seedlm4_tasks.py holdout --model s12-a1 --verdicts
python scripts/seedlm10_ensemble.py --coders s12-a1 s12-a2 s12-a3 s12-b1 s12-b2 s12-b3 --output reports/seedlm/ensemble_s12.json
```
