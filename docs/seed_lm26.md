# SeedLM-26~29: 같은 과제를 다른 말로 읽히기

작성일: 2026-11-21. [SeedLM-25](seed_lm21.md)에서 코더의 오답은 설명을 그렇게 읽은 결과라는 것을 보았다. 학습 과제는 저마다 한 가지 문장으로만 나오므로, 코더는 뜻보다 그 문장을 배운다. 이 문서는 학습 과제의 설명을 교사가 다른 말로 바꿔 써서 함께 읽힌 실험들을 모은다. 측정은 모두 측정 전에 등록했다.

## 요약

- 교사 서브에이전트 셋이 학습 과제 1,200개(실제 과제 525, 교사 과제 675)의 설명을 과제마다 두 가지로 바꿔 썼다. 2,400개 모두 기계 검사(설명 속 숫자와 따옴표 문자열이 같은 순서로 남음, 원문·서로와 다름)를 통과했다(`data/seedlm/paraphrase/`).
- 같은 체크포인트에서 400걸음씩, 이 과제들을 원문으로 두 번 더 읽히는 갈래와 바꿔 쓴 두 문장으로 읽히는 갈래를 쌍으로 비교했다(SeedLM-26). 교사 보류 과제에서 +4, +6, −2(평균 +2.7)로 판단 보류다. 개발 과제는 +1.3, 짧게 줄인 설명은 0이다.
- 처음부터 80분 학습에 섞어도 교사 보류 과제의 과적합은 그대로였다(SeedLM-27, 기각). 실제 개발 과제에서는 시드 셋 평균 +2.7(판단 보류, SeedLM-28)로, 셋 중 둘이 혼자 61개를 풀었지만 시스템은 67~68로 그대로였다. 투표자로서도 합의를 올리지 못했다(SeedLM-29).
- 차이의 대부분은 대조 갈래가 잃은 것이다. 원문을 되풀이한 갈래는 기준 코더보다 교사 보류 과제를 3개쯤 잃었고, 바꿔 쓴 갈래는 잃지 않았다. 바꿔 쓴 문장은 새 능력이라기보다 문장을 외우는 것을 막는 장치로 일했다.

## 1. 바꿔 쓴 문장 (SeedLM-26의 데이터)

교사마다 과제 400개를 맡아, 설명 하나에 두 문장을 썼다. 첫째는 문장 전체를 다시 짠 것이고, 둘째는 연습 문제 제목처럼 짧게 줄인 것이다. 같은 함수가 풀어야 하고, 요구를 더하거나 빼지 않으며, 원문이 모호하면 모호한 그대로 둔다. 교사는 그 과제의 설명과 보이는 예시 하나만 봤다. 검사기(`scripts/seedlm26_paraphrase_check.py`)는 코더가 설명에서 읽는 상수(숫자, 따옴표 문자열, "space"나 "comma" 같은 문자 이름)가 같은 값, 같은 순서인지 본다. 프로그램은 상수를 순서로 가리키기 때문이다. 교사들은 예시가 설명과 어긋나는 과제에서도 설명을 따랐고, "print" 같은 흐린 동사도 고치지 않았다.

## 2. 쌍 미세조정 (SeedLM-26)

기준 코더 s12-a1~a3마다 같은 체크포인트에서 두 갈래를 400걸음씩 돌렸다(`scripts/seedlm26_finetune.py`, `reports/seedlm/seedlm26_protocol.json`). 두 갈래 모두 기준 실행의 데이터에 이 1,200개 과제의 행을 10% 더한다. 대조(s26-o)는 원문을 두 번, 처리(s26-p)는 바꿔 쓴 두 문장을 쓴다. 프로그램과 예시는 같고 단어만 다르다.

| 맞힌 과제 | 기준 코더 | 원문 반복 (o) | 바꿔 쓴 문장 (p) | p − o |
|---|---|---|---|---|
| 교사 보류 139 (a1 / a2 / a3) | 59 / 59 / 62 | 58 / 55 / 58 | 62 / 61 / 56 | **+4 / +6 / −2** (평균 +2.7) |
| 개발 과제 94 | 56 / 53 / 58 | 59 / 51 / 56 | 59 / 54 / 57 | 0 / +3 / +1 (평균 +1.3) |
| 짧게 줄인 교사 보류 139 (SeedLM-8) | | 57 / 57 / 62 | 60 / 54 / 62 | +3 / −3 / 0 |

주 측정은 +3 이상이면 지지, 0 이하면 기각으로 정했다. +2.7이라 판단 보류다. 처리 갈래가 기준 코더보다 나아진 것은 아니다(교사 보류 평균 59.7 대 60.0). 다른 점은 대조 갈래가 원문을 되풀이하며 3개쯤 잃었다는 것이다. 같은 문장을 더 읽히면 외우고, 다른 문장으로 읽히면 외우지 않는다. 짧게 줄인 설명을 더 잘 읽게 되지는 않았다.

## 3. 처음부터 80분, 바꿔 쓴 문장과 함께 (SeedLM-27)

코더는 학습 30분쯤에 보류 과제 점수가 가장 높고 그 뒤로 떨어진다(SeedLM-8). 같은 문장을 수십 번 되풀이해 외우기 때문이라면, 바꿔 쓴 문장을 섞으면 그 뒤로도 오를 것이다. s12-a1의 인자로 80분씩 두 번 학습했다. 대조(s27-c)와, 1,200개 과제가 다른 두 문장으로도 나오는 처리(s27-p, `--paraphrases`)다. 20분마다 체크포인트를 남겼다(`reports/seedlm/seedlm27_protocol.json`, 측정 전 등록, 시드는 한쪽에 하나).

| 맞힌 과제 (20 / 40 / 60 / 80분) | 대조 s27-c | 바꿔 쓴 문장 s27-p |
|---|---|---|
| 교사 보류 139 | 51 / 47 / 53 / 51 | 49 / 51 / 52 / 53 |
| 개발 과제 94 | 57 / 61 / 54 / 58 | 52 / 59 / 59 / **61** |

주 측정(교사 보류 과제에서 60·80분 평균 − 20·40분 평균, 처리 − 대조)은 −0.5라 기각이다. 두 코더 모두 80분 끝에 교사 보류 과제 52개 안팎으로, 40분에 끝낸 어떤 코더(59~62)보다 낮다. 바꿔 쓴 문장은 긴 학습의 과적합을 막지 못했다(중간 체크포인트는 학습률이 덜 내려간 상태라 두 갈래 사이에서만 비교한다). 개발 과제에서는 처리 갈래가 52 → 59 → 59 → 61로 꾸준히 올라, 같은 대비가 +7.5다. 실제 과제 525개를 바꿔 쓴 문장이 들어간 덕일 수 있지만, 시드 하나라 단서일 뿐이다. 시스템에 넣으면 두 코더 모두 개발 과제 68로, s5-var의 69를 넘지 못했다. s27-p 혼자 맞히는 61개는 대부분 엔진도 푸는 과제라, 엔진을 덮어쓰면 고침 3, 깨뜨림 7이다.

## 4. 시드 셋으로 다시 (SeedLM-28)

SeedLM-27에서 개발 과제가 오른 것이 시드 하나의 우연인지 보려고, 같은 80분 쌍을 시드 2, 3으로 더 학습했다(`reports/seedlm/seedlm28_protocol.json`, 측정 전 등록).

| 80분, 맞힌 과제 (시드 1 / 2 / 3) | 대조 | 바꿔 쓴 문장 | 차이 |
|---|---|---|---|
| 개발 과제 94, 혼자 | 58 / 57 / 54 | 61 / 55 / 61 | +3 / −2 / +7 (평균 **+2.7**) |
| 교사 보류 139 | 51 / 59 / 58 | 53 / 61 / 56 | +2 / +2 / −2 (평균 +0.7) |
| 시스템 (엔진 + 코더), 최고 방법 | 67 | 68 / 67 / 67 | |

주 측정(개발 과제 차이의 평균)은 +2.7로, +3에 조금 못 미쳐 판단 보류다. 바꿔 쓴 문장 코더는 혼자 평균 59.0개로, 셋 중 둘이 61개를 풀었다. 지금까지 후위 코더가 혼자 푼 가장 많은 수다. 하지만 시드 사이 흔들림이 효과만큼 크고, 시스템에 넣으면 67~68로 s5-var의 69를 넘지 못한다. 더 푸는 과제가 엔진도 푸는 과제이기 때문이다.

## 5. 투표자로서 (SeedLM-29)

따로 배운 코더들의 합의만이 순위를 바꿨으므로, 다른 문장으로 배운 코더가 더 독립적인 투표자인지 봤다. 코더 24개(SeedLM-21의 합의)에 바꿔 쓴 문장 코더 셋을 더한 것과 80분 대조 코더 셋을 더한 것을 비교했다(`reports/seedlm/seedlm29_protocol.json`).

| 코더만의 합의 (순서 200개 평균) | 24개 | + 바꿔 쓴 문장 3 | + 대조 3 |
|---|---|---|---|
| 개발 과제 94 | 64.72 | **64.76** | 63.72 |
| 교사 보류 139 | 72.17 | 70.62 | 73.22 |
| 엔진과 같은 무게 (개발 과제) | | 68 | 68 |

바꿔 쓴 문장 쪽이 대조 쪽보다 개발 과제에서 1.0 높지만 엔진(65)을 넘지 못해 판단 보류다. 24개와 비교하면 바꿔 쓴 문장 코더는 개발 과제에 보탠 것이 없고 교사 과제를 1.6 깎았다. 엔진과 합친 결과도 두 쪽 모두 68이다.

## 한계

- 1,200개는 학습 과제의 일부다(교사 과제 1,308개 중 675개, 변형·합성 과제는 없음).
- 미세조정은 400걸음이고, 처음부터 학습은 갈래마다 시드 셋이다.

## 재현

```bash
python scripts/seedlm26_paraphrase_check.py --all --summary
for k in 1 2 3; do
  python scripts/seedlm26_finetune.py --base s12-a$k --name s26-o$k --words original --steps 400
  python scripts/seedlm26_finetune.py --base s12-a$k --name s26-p$k --words paraphrase --steps 400
  python scripts/seedlm15_ensemble_scaling.py cache --coders s26-o$k s26-p$k
  python scripts/seedlm8_terse.py --model s26-o$k; python scripts/seedlm8_terse.py --model s26-p$k
done
python scripts/seedlm23_compare.py --pairs s26-p1:s26-o1 s26-p2:s26-o2 s26-p3:s26-o3 --output reports/seedlm/paraphrase_compare.json
python scripts/seedlm4_train.py --name s27-c --minutes 80 --d-model 320 --layers 8 --heads 10 --views 3 --seed 1 --variant-share 0.1 --save-every 20
python scripts/seedlm4_train.py --name s27-p --minutes 80 --d-model 320 --layers 8 --heads 10 --views 3 --seed 1 --variant-share 0.1 --save-every 20 --paraphrases
python scripts/seedlm15_ensemble_scaling.py cache --coders s27-c-m20 s27-c-m40 s27-c-m60 s27-c s27-p-m20 s27-p-m40 s27-p-m60 s27-p
```
